# English Together

Сайт для самостоятельного изучения английского от первых слов до сложной речи. В текущей версии есть **7 уровней, 56 авторских уроков и 7 мини-игр**. Каждый урок содержит объяснение по-русски, примеры, новые слова, короткий диалог с озвучиванием браузером, чтение, задание на письмо и речь, тест. Прогресс, личное расписание и интервальные повторения хранятся в Supabase.

## Запуск локально

```bash
npm ci
npm run dev
```

Открой адрес, который покажет Vite. Для проверки алгоритма повторения: `npm test`. Для production-сборки: `npm run build`.

## Как устроено обучение

1. Ученик регистрируется по email и паролю, подтверждает адрес и входит. Из формы входа можно отправить письмо для сброса пароля.
2. При первом входе выбирает имя, дни недели и минуты занятий. План можно изменить.
3. В уроке читает теорию, слушает диалог, выполняет письменное и устное задания, затем отвечает на три вопроса. Два верных ответа дают отметку о прохождении. Самооценка понимания хранится отдельно от тестового балла.
4. Пройденный урок появится в повторении через 1 день. При успешных повторениях интервалы растут до 3, 7, 14, 30, 60 и 120 дней. Ошибка возвращает тему через день.
5. У каждого уровня есть сюжетная мини-игра. Прогресс и лучший результат игры сохраняются для каждого аккаунта отдельно.

Автоматическая проверка покрывает вопросы с вариантами ответа. Свободную речь и письмо ученик выполняет и оценивает самостоятельно. Прохождение уроков не равно официальному подтверждению уровня CEFR.

## База данных

Проект Supabase: `English Together` (`sknwfnucvwneirhcoxhq`). Структура создана из [`supabase/schema.sql`](supabase/schema.sql). На всех пяти таблицах включена RLS: пользователь видит и меняет только свои строки. В браузере используется только publishable API key, который по назначению является публичным. Secret и service-role ключи нельзя добавлять в репозиторий.

### Письма для открытой регистрации

Supabase по умолчанию отправляет письма только адресам участников организации. Для регистрации любого желающего нужен внешний SMTP-провайдер. Один из вариантов — Brevo: создать аккаунт, включить транзакционную почту, указать отправителя и сгенерировать SMTP-ключ. Затем в панели Supabase открыть **Authentication → SMTP Settings**, включить Custom SMTP и указать host, port, login, key и sender. SMTP-ключ вводится **только в панели Supabase**, не в коде и не в GitHub.

Если нет своего домена, Brevo может заменить адрес отправителя своим техническим адресом. Для надёжной доставки писем в будущем лучше добавить собственный домен и настроить DKIM/DMARC. Перед публичным запуском отправь тестовое письмо и проверь регистрацию, подтверждение адреса и вход.

Официальные инструкции: [Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp), [Brevo SMTP-ключ](https://help.brevo.com/hc/en-us/articles/7959631848850-Create-and-manage-your-SMTP-keys).

## GitHub Pages

1. Создай публичный репозиторий `english-together` и отправь в него файлы этой папки. Папки `node_modules` и `dist` исключены через `.gitignore`.
2. В **Settings → Pages → Build and deployment** выбери **GitHub Actions**. Файл `.github/workflows/deploy.yml` проверит тесты, соберёт сайт и опубликует `dist` при push в `main`.
3. В Supabase открой **Authentication → URL Configuration**. В `Site URL` укажи итоговый адрес `https://<пользователь>.github.io/english-together/`. В `Redirect URLs` добавь этот же адрес и локальный `http://127.0.0.1:5173/` на время разработки.
4. После настройки SMTP зарегистрируй два отдельных аккаунта и проверь, что у каждого свой план и прогресс.

GitHub Pages размещает статические HTML/CSS/JS-файлы. Данные и регистрация работают через Supabase. [Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Где менять содержимое

- `src/course/pre-a1.js` — первые шаги;
- `src/course/a1.js` … `c2.js` — уровни CEFR;
- `src/course/index.js` — общий каталог и нормализация заданий;
- `src/learning.js` — оценки, интервалы повторения и план;
- `src/main.js` — интерфейс и сохранение данных.

Все тексты уроков написаны для этого проекта. Их можно расширять: увеличивать число упражнений, добавлять оригинальные записи живой речи и задания с обратной связью преподавателя.
