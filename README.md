# English Together

Сайт для самостоятельного изучения английского от первых слов до сложной речи. В текущей версии есть **7 уровней, 56 авторских уроков и 7 мини-игр**. Каждый урок содержит объяснение по-русски, примеры, новые слова, короткий диалог с озвучиванием браузером, чтение, задание на письмо и речь, тест. Прогресс, личное расписание и интервальные повторения хранятся в Supabase.

## Запуск локально

```bash
npm ci
npm run dev
```

Открой адрес, который покажет Vite. Для проверки алгоритма повторения: `npm test`. Для production-сборки: `npm run build`.

## Как устроено обучение

1. Ученик регистрируется по email и паролю и сразу входит без письма подтверждения.
2. При первом входе выбирает имя, дни недели и минуты занятий. План можно изменить.
3. Урок начинается с короткого вопроса с мгновенной подсказкой: ученик сначала пробует ответить, затем читает объяснение и примеры. После этого он слушает диалог, выполняет письменное и устное задания и отвечает на три вопроса. Два верных ответа дают отметку о прохождении. Самооценка понимания хранится отдельно от тестового балла.
4. Пройденный урок появится в повторении через 1 день. При успешных повторениях интервалы растут до 3, 7, 14, 30, 60 и 120 дней. Ошибка возвращает тему через день.
5. У каждого уровня есть сюжетная мини-игра. Прогресс и лучший результат игры сохраняются для каждого аккаунта отдельно.
6. В личном плане можно сменить пароль, введя текущий пароль.
7. Внизу личной страницы показаны средние баллы по шести календарным неделям и последние темы, которые стоит доучить. Рекомендации учитывают ошибку в повторении, низкий балл, незавершённый урок, самооценку и наступивший срок повторения.

График строится по тестам уроков, играм и повторениям. Если за неделю нет баллов, он показывает «нет данных», а не ноль. Автоматическая проверка покрывает вопросы с вариантами ответа. Свободную речь и письмо ученик выполняет и оценивает самостоятельно. Прохождение уроков не равно официальному подтверждению уровня CEFR.


### Регистрация без писем

В **Authentication → Sign In / Providers** разрешена регистрация новых пользователей, включён Email, а **Confirm email** выключен. SMTP не подключён. После ввода email и пароля Supabase сразу создаёт аккаунт и сеанс. Адрес почты служит логином; владение адресом не проверяется.

Письма для восстановления пароля недоступны. Сохрани пароль в менеджере паролей. Сменить его можно после входа в разделе «План», указав текущий пароль. Если пароль утрачен и активного сеанса нет, восстановить доступ через сайт нельзя: потребуется ручная помощь администратора. Для публичной регистрации без подтверждения адреса есть риск создания аккаунта на чужую почту, поэтому перед публикацией проверь этот компромисс и не используй такой режим для чувствительных данных.


Все тексты уроков написаны для этого проекта. Их можно расширять: увеличивать число упражнений, добавлять оригинальные записи живой речи и задания с обратной связью преподавателя.
